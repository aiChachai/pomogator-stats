# Pomogator · статистика

Репозиторий агрегатов бота для сайта pomogator.com.ar.
Бот записывает `stats.json`, когда меняются данные. В первом
реальном выпуске файл создаёт экспорт бота. До этого проверка
справедливо сообщает, что файл отсутствует.

- Схема находится в `schema/stats.schema.json`.
- `npm ci --ignore-scripts` и `npm run validate` проверяют файл на Node.js 24.22.3.
- Малые общие счётчики сохраняются. Разбивки с малыми числами и
  вторичным скрытием приходят как `null`.
- В `stats.json` допустимы только агрегаты. Лицензия данных — CC BY 4.0.

GitHub Actions при изменениях в `main` проверяет данные и вызывает
Vercel deploy hook только после успешной проверки. Секрет
`VERCEL_DEPLOY_HOOK` добавляется при S3. Схема и скрипт проверки
совпадают с проверкой `pomogator-site`.
